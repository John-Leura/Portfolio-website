Interactive shopping list

A browser script for adding and removing shopping items while keeping an item count in sync.

Technical approach

  • Rejects blank input before creating a list item.
  • Creates item labels with text nodes and attaches a click listener to remove each item.
  • Updates the count after every addition or removal and clears the input after adding.

Scope: Client-side interaction; items are not persisted between page loads.

Client-side form validation

A validation script that gives field-level feedback when a visitor leaves an input.

Technical approach

  • Uses reusable functions to check names, email addresses, phone numbers, minimum lengths, and empty comments.
  • Connects blur events to feedback elements and Bootstrap success or error classes.
  • Requires a ten-digit phone number and nonempty comments.

Scope: Browser-side feedback; this script does not provide server-side validation or authentication.
